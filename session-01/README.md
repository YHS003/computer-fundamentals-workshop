# 💻 Session 01 – Computer Fundamentals

## Overview

This session introduces the fundamental concepts of how a computer works. Before learning programming, it is important to understand the hardware, software, and the operating system that make everything possible.

---

## Topics Covered

- What is a Computer?
- Hardware vs Software
- Computer Components
  - CPU
  - RAM
  - Storage (HDD & SSD)
  - Motherboard
  - Power Supply
- Input & Output Devices
- Introduction to Operating Systems

---

## Learning Outcomes

After completing this session, you should be able to:

- Understand the role of each computer component.
- Differentiate between hardware and software.
- Explain the purpose of an operating system.
- Build a solid foundation before learning programming.
