# 👨‍💻 Session 03 – Programming Fundamentals

## Overview

This session introduces the history of programming, how programming languages evolved, and why there are many different programming languages today.

---

## Topics Covered

- What is Programming?
- History of Programming
- Transistors
- Machine Language
- Assembly Language
- Compiler
- High-Level Programming Languages
- Why are there many programming languages?
- Programming Fields

---

## Learning Outcomes

After completing this session, you should be able to:

- Understand how programming evolved.
- Explain the difference between machine language, assembly, and high-level languages.
- Understand the purpose of compilers.
- Recognize the main programming fields.
