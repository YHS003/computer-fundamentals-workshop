# 🌐 Session 02 – Internet Fundamentals

## Overview

This session explains how the Internet works behind the scenes using simple real-world examples and practical demonstrations.

---

## Topics Covered

- What is the Internet?
- Computer Networks
- Router
- Server
- Firewall
- IP Address
- DNS
- What happens when you send a WhatsApp message?

---

## Learning Outcomes

After completing this session, you should be able to:

- Understand the basics of networking.
- Explain the purpose of IP and DNS.
- Describe the role of routers, servers, and firewalls.
- Understand the journey of data across the Internet.
